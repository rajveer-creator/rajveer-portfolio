# Project: Rajveer Gurjar — Developer Portfolio

## 1. Vision & Overview
An editorial, minimalist personal portfolio website for Rajveer Gurjar (B.Tech CSE AI student at Mandsaur University). Built to showcase real software systems, AI prototypes, academic progression, and technical learning with authentic, human-crafted design and zero fake fluff.

## 2. Core Principles & Governance
1. **Permanent Responsive-First Rule (`AGENTS.md`, `GEMINI.md`):**
   - Mandatory test viewports: 360px, 390px, 540px, 768px, 1024px, 1440px, 1882px.
   - Zero horizontal overflow (`overflow-x: hidden`, `width: 100%`).
   - 44px minimum touch targets on mobile controls; stacked mobile buttons; custom cursor disabled `< 1024px`.
2. **Ponytail, Lazy Senior Dev Mode:**
   - Solve problems with the least new code. Scope discipline.
   - No unnecessary abstractions, wrappers, or "for later" features.
   - Verifiable checks and error handling preserved.
3. **Truth in Advertising:**
   - No fabricated metrics, benchmark numbers, fake users, or invented deployment claims.
   - No claims of custom-trained neural networks when using API-based inference.
   - Transparent reporting of prototypes vs. production systems.

## 3. Technology Baseline
- **Frontend Stack:** React 18, Vite 6, Tailwind CSS 3.4, React Router DOM 6.28, Framer Motion 14, Lucide React.
- **Verification Harness:** `npm --prefix frontend run build` (vite build).
- **Directory Root:** `project root`
